# Quiet Clock

Quiet Clock is a lightweight native macOS desktop widget displaying hours and minutes with a rounded system font and subtle text shadow.

See [[architecture#Architecture]] for rendering, scheduling, and packaging, and [[tests#Validation]] for automated and desktop checks. [README.md](../README.md) contains build and installation instructions.
