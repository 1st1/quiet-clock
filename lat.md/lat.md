# Quiet Clock

Quiet Clock is a native macOS transparent desktop clock displaying hours and minutes with a rounded system font and subtle text shadow.

See [[architecture#Architecture]] for rendering, scheduling, and packaging, and [[tests#Validation]] for automated and desktop checks. See [[setup#Setup]] for build and installation instructions. The project uses the [MIT license](../LICENSE).

- [[architecture]] — Desktop rendering, scheduling, and packaging.
- [[tests]] — Automated checks and interactive desktop verification.

- [[setup]] — Build, install, customize, and validate the app.
